# Review priority
1. Correctness.
2. Regression risk.
3. Architecture boundary violations.
4. Missing validation/tests.
5. Unnecessary complexity.
6. Style.

Use concrete findings with file/symbol evidence. Do not generate style noise to make the review look busy.

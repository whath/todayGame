# Workflow
1. Read the narrowest relevant docs and code.
2. Map current ownership and execution path.
3. Reuse existing interfaces before adding abstractions.
4. Implement the smallest defensible change.
5. Do not refactor unrelated code.
6. Run relevant checks.
7. Provide manual playtest steps if behavior changed.
8. Update architecture/decision/devlog docs only when materially affected.
9. Return implemented files, validation, known issues, and next step.

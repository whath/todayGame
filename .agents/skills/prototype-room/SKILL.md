# Scope
Create only what validates foundation systems:
- floor,
- boundaries,
- simple obstacles,
- P1 spawn,
- P2 spawn.

No formal art, enemies, weapons, progression, or decorative systems.
Verify both players, collision, and shared camera in the room.

# Workflow
1. Read `AGENTS.md` and relevant files in `docs/`.
2. Inspect repository and Cocos project structure.
3. Inspect Git status without changing user work.
4. Identify current scenes, prefabs, scripts, and system owners.
5. Report broken assumptions, missing docs, build/config risks, and unclear ownership.
6. Do not add gameplay during an audit.
7. End with the smallest next task and its acceptance criteria.

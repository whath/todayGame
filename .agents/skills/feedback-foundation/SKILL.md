# Rules
- Gameplay requests semantic feedback; presentation selects concrete effects.
- Centralize Reduce Screen Shake, Reduce Flashing and Vibration modifiers.
- Do not scatter camera/audio/rumble calls through gameplay.
- Start only with feedback types required by current prototypes.

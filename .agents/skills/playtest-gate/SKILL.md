---
name: playtest-gate
description: Use at the end of a milestone or foundation task to produce a deterministic local-multiplayer manual playtest checklist with PASS/FAIL results.
---

# V0.1 baseline checks
- Windows startup
- Keyboard + Keyboard
- Keyboard + Gamepad
- Gamepad + Keyboard
- Gamepad + Gamepad
- simultaneous movement
- player independence
- shared camera
- collision/bounds
- controller disconnect/reconnect state
- restart/re-enter flow
- console errors

Record PASS/FAIL and exact failure notes. Do not mark a milestone passed with unresolved mandatory failures.

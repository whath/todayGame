# Design Pillars — v5

## Fixed
1. 3D.
2. Two-player local multiplayer is the first playable form.
3. Windows PC is the primary development platform.
4. Input/gameplay architecture must not block future networking.
5. Final genre is intentionally undecided.
6. Content should become increasingly data-driven after direction lock.

## Not fixed
- Co-op vs competitive.
- Fighting / racing / management / action / puzzle / sports / narrative / hybrid.
- Linear story.
- Combat.
- Camera style.
- Progression model.
- Networking model.

## Asset sourcing
Primary free sources:
- Quaternius
- Fab
- itch.io

User approves style/assets; Codex handles technical intake and integration.

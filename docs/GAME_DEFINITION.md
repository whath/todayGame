# 游戏定义 — 合作实验方向 v0.1

本页是当前实验的工作假设，后续由双人试玩决定保留或修改，尚未确定最终题材与商业范围。

**一句话体验：** 两名搭档进入失去供电的设施，通过互相守门、恢复机关和接应，一起抵达出口。

**玩家与平台：** Windows PC 本地同屏双人，面向愿意交流、操作水平可能不同的朋友或家人；沿用键盘、键盘 + 手柄、双手柄。当前阶段不增加联网和单人 AI。

**合作的必要性：** 一个玩家维持条件，另一个玩家利用窗口推进；推进后解除限制，让原先留下的伙伴也能通过。角色能力暂时相同，职责由玩家协商，允许交换分工。

**核心循环：** 观察机关 → 沟通分工 → 尝试行动 → 读取反馈 → 帮助伙伴通过 → 共同到达目标。希望产生“我为你创造机会，你回来接应我”的默契，而不是一人操作、另一人观看。

**首个实验：守门与接力。** 左侧踏板临时开门；另一玩家穿门，在终端附近按交互键使门保持开启；两人进入右侧出口才完成。终端必须由踏板上的玩家以外的队友操作。门口有人时不关门夹人。没有倒计时、生命和惩罚；松开踏板是可恢复的失误，暂停菜单或 F5 可重开。

**体验目标：** 首个实验是一段几分钟的机制验证，不宣称已经达到 10 分钟完整试玩。后续用同一机制的引导、变式和组合形成约 10 分钟样板；样板完成前不承诺总关卡数或上线日期。

**UI 与叙事：** 当前只做目标、机关标签、每位玩家的操作提示和通关反馈；保留几何占位。设施背景只解释合作动机，暂不写完整故事章回、过场或对白系统。

**验证标准（待实机）：** 邀请至少 3 对未读开发文档的玩家，观察是否能自行发现分工、终端操作和双人出口；记录卡住地点、最长连续等待、是否需要口头提示、交换角色后是否愿意再玩。不能仅凭代码测试宣称“好玩”。

**保留／修改条件：** 多对玩家能理解配合并主动沟通，才扩展第二个挑战；若主要问题是看不懂，先改提示与布局；若规则清楚仍无趣，改变合作机制，暂缓制作更多关卡和正式美术。

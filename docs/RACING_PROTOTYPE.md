# 赛车类别 · R0 驾驶验证

用户方向：偏真实驾驶、本地双人、接受分屏、卡通赛车/赛道、无 AI；赛车作为长期主要类别。当前是灰盒实现，未经实机手感验收。

## 已接入
- 类别选择 → 赛车 → 双人加入/选车/准备/赛道 → 3 秒倒计时 → 3 圈比赛 → 结果 → 重赛/重新选车/类别入口。
- 旅行车和跑车两种配置，分别拥有质量、动力、刹车和抓地参数；简单车身/低车顶区别，P1/P2 身份条纹和颜色。
- 一条闭合训练场，12 个顺序检查点，直道、不同弯道和 2 米起伏。赛道选择数据入口已接通，本轮仅一条，不伪造第二个选项。
- Cocos 动态刚体车身、盒碰撞、重力与 CCD；四轮向道路射线检测；弹簧/阻尼悬挂、接地点速度、合成纵向和侧向轮胎力、摩擦圆、空气阻力。转向速率受限，高速减小转角；停稳持续刹车 0.7 秒后倒车，倒车动力/最高驱动速度较低。
- 两个透视跟车相机，各占半屏；每人速度、圈数、位置排名、时间、下一检查点，统一设置/暂停覆盖层。
- 手动复位和掉出世界复位；回到最后已通过检查点后的独立车道，保留下一检查点顺序，不增加圈数；优先使用本车道内的备用复位点，全部被占用时等待，不直接压到另一辆车。
- 完赛先后按最后检查点扫掠交点的子步内时间排序；未完赛排名按圈数、最后检查点及段内投影估算。

## 操作
| 功能 | 默认 P1 / P2 键盘 | 手柄 |
| --- | --- | --- |
| 选车 | E / L（交互动作） | West |
| 准备 | G / K（次动作） | East |
| 菜单确认 | Enter | South |
| 转向 | A、D / 左、右 | 左摇杆 X / 十字键 X |
| 油门 | W / 上 | RT 模拟量 |
| 刹车，停稳持续按住倒车 | S / 下 | LT 模拟量 |
| 复位 | E / L（交互动作） | West |
| 暂停 | Esc | Options / Start |

键盘映射继续使用设置中的玩家绑定。转向/油门为独立语义轴，不因对角线归一化降低全油门。手柄选车/准备不会同时触发返回或确认开赛。实际设备组合仍 NOT RUN。

## 物理与时间
默认 Creator 3.8.6 使用 Bullet (physics-ammo)；本机既有 preview import-map 确认包含该模块。未裁剪引擎模块，没有添加第三方运行库。若项目被改成 Builtin/None，进入赛车明确报错，不能用无动力学后端假装完成驾驶。

应用组装记录并临时关闭 PhysicsSystem 自动模拟；赛车按 gameDelta 以 1/120 秒固定步进（每帧最多积累 0.2 秒），暂停/设置/失焦/断线没有物理步进；退出应用入口恢复自动模拟与碰撞矩阵。group 1 是赛车、2 是道路、4 是护栏；轮胎射线只检测道路，车身可碰其他车、路面与护栏。长帧不补算整个离开时间。

RaceSession 不依赖 Cocos，检查点使用有向线段扫掠、赛道宽度和高度范围，倒着过线、漏检查点和大位移传送不计数。复位不送进度。轮胎力是简化模型，不声称工程级车辆仿真；没有轮胎温度、复杂传动/档位、损伤、力反馈方向盘或车辆 AI。

## 待验收
本轮按用户要求不主动打开前台。刚体稳定性、弯道接缝/护栏、坡道、CCD、高速碰撞、分屏可读性和相机遮挡尚未实机检验；不能仅根据公式/类型通过认定手感偏真实。跟车镜头当前没有遮挡避让，正式环境资产引入前必须补测。当前没有声音素材、赛车记录存储、第二条赛道或正式美术。

下一步先用训练场驾驶记录决定 ITERATE；车辆起步/制动/连续转弯/复位可靠后，再扩第二赛道和卡通资源。类别分层见 GAME_CATEGORIES，验收表见 VALIDATION_RACING_R0。

# 参考资料

- 用户提供的 [游戏开发总规划](reference/GAME_DEV_CODEX_MASTER_PLAN.md)：需求与架构边界来源。
- [Cocos 3.8 输入事件](https://docs.cocos.com/creator/3.8/manual/zh/engine/event/event-input.html)：键盘和手柄事件入口。
- [EventGamepad API](https://docs.cocos.com/creator/3.8/api/en/class/EventGamepad)：通过事件取得游戏手柄设备。
- [Cocos 3.8.6 原生手柄适配](https://github.com/cocos/cocos-engine/blob/v3.8.6/pal/input/native/gamepad-input.ts)：平台层输入字段参考。
- [Cocos 3.8.6 Web 手柄适配](https://github.com/cocos/cocos-engine/blob/v3.8.6/pal/input/web/gamepad-input.ts)：平台层输入字段参考。
- [RenderRoot2D](https://docs.cocos.com/creator/3.8/manual/en/ui-system/components/editor/renderroot2d.html)：世界与 HUD 的 2D 渲染入口。

阅读 API 资料用于编写代码，不代表已执行或验证生成工程。

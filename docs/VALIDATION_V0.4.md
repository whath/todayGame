## 将来恢复实机验收时

先按 VALIDATION_V0.3 的基础 Gate 检查导入、设备、菜单、保存和构建，再检查本轮内容。版本号进入 v0.4-dev 不代表 v0.3.1 实机 Gate 已通过。

1. 新游戏 → 两人加入 → 开始；确认目标、踏板、门、终端和出口标签清楚。
2. 任一玩家踏板开门，伙伴穿过并按当前交互绑定；松开踏板仍保持开门。交换分工重复。
3. 测试提前松开踏板、角色站在门中、同时移动、手柄断开、失焦、设置菜单，确保可恢复且不误触终端。
4. 一人到出口不成功，两人到达才成功；结果菜单支持手柄再试、设置和回主菜单。
5. 终端检查点保存后退出并继续，位置和永久开门状态恢复；完成存档恢复为结果界面。重开后机关清空，Profile 完成记录保留。
6. 检查实际 UI 层级、共享镜头、字号与提示，并验证 Windows 包。

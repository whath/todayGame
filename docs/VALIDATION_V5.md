## 本轮发现并修复
- 标准材质未作为资源依赖加载，运行时 effectName 不能保证 effect 存在，出现空 passes、localSetLayout 与随后销毁异常。加入 Greybox.mtl 场景引用，使用标准材质的 mainColor 属性并在缺失依赖时显式报错；重新打开场景后复测。
- 引擎打开的场景缓存尚未更新时，新的序列化材质属性为空。切换场景并重新打开 Prototype 使磁盘依赖生效。外部修改场景后需重开，不能只刷新浏览器。
- 初版共享相机以玩家中点取景导致出生在左侧时房间偏移。恢复房间边界约束，并添加 UI 层投影标记。

## 下一次手动验收
1. 新游戏，P1 WASD、P2 方向键；识别球形 P1 / 方柱 P2，确认不能穿过关闭的门和墙。
2. 一人站踏板，另一人通过门并用 E/L 操作终端；交换职责再走一次；两人进入蓝色出口。
3. 门口停人时松踏板，确认防夹；分别在机关前后保存/返回/读档，核对位置、永久开门和完成状态。
4. 暂停/设置期间动作不推进，退出后正常；重开与反复返回无模型/材质错误。
5. 用四种输入组合检查归属、热插拔、菜单接管；之后构建 Windows 开发版重复流程。
